# Chemoggstry

Chemoggstry — это интерактивное образовательное веб-приложение с элементами ИИ, созданное для помощи студентам в изучении оптимизации химических реакций. Оно стирает грань между теоретической химией и практическими экспериментами, симулируя лабораторную среду, где пользователи могут оптимизировать условия реакций и получать умные объяснения от встроенного ИИ-ассистента.

## Возможности

*   **Интерактивная таблица Менделеева:** Просматривайте и выбирайте элементы прямо в красивой таблице для поиска и выбора химических реакций.
*   **Движок оптимизации реакций:** Проводите симулированные эксперименты для поиска оптимальных условий (температура, концентрация, катализатор, время реакции) для выбранной реакции. Выбирайте цель: *Максимизировать выход продукта* или *Минимизировать время реакции*.
*   **ChemAI Assistant:** Умный, контекстно-зависимый ИИ-ассистент, который анализирует вашу текущую итерацию эксперимента и отвечает на вопросы вроде:
    *   *"Почему был выбран этот катализатор?"*
    *   *"Почему изменилась температура?"*
    *   *"Почему мой фактический выход отличается от предсказанного?"*
*   **Анализ выхода продукта в реальном времени:** Сравнивайте предсказанный выход с фактическим и визуализируйте прогресс вашей оптимизации.
*   **Чистый и современный UI:** Адаптивный интерфейс в стиле glassmorphism, написанный на React.

## Архитектура

Проект представляет собой full-stack JavaScript приложение в формате монорепозитория, разделённое на фронтенд и бэкенд.

*   **Frontend (`/frontend`)**:
    *   **React (Vite)**: Быстрый UI на базе компонентов.
    *   **State Management**: React Hooks (`useState`, `useCallback`, кастомные хуки вроде `useExperimentRunner`).
    *   **Styling**: Чистый CSS с использованием CSS переменных для удобной стилизации.
    *   **Архитектура**: Выделенные API клиенты (`apiClient.js`), модульные UI компоненты и страницы.

*   **Backend (`/backend`)**:
    *   **Node.js & Express**: Надежный REST API.
    *   **In-Memory Data Store**: Быстрые JSON-репозитории (`dataRepository.js`), выступающие в роли базы данных для реакций, элементов и истории экспериментов.
    *   **Service Layer**: Бизнес-логика отделена от HTTP-контроллеров (например, `checkReactionService.js`, `efficiencyService.js`, `runService.js`).
    *   **AI Context & Templating**: Детерминированный ИИ-движок (`questionMatcher.js`, `assistantResponder.js`), использующий нормализацию текста и систему баллов по ключевым словам для точных, лишенных галлюцинаций образовательных ответов.

## Начало работы

### Требования

*   Node.js (рекомендуется v18 или выше)
*   npm

### Установка

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/Ayau1ym335/chemoggstry.git
    cd chemoggstry
    ```

2.  **Установите зависимости (в корне, на бэкенде и фронтенде):**
    ```bash
    npm install
    cd backend && npm install
    cd ../frontend && npm install
    cd ..
    ```

### Запуск приложения

Для одновременного запуска бэкенда и фронтенда (с помощью concurrently), выполните следующую команду из корневой директории:

```bash
npm run dev
```

*   **Backend API** будет доступен на `http://localhost:4000`
*   **Frontend UI** будет доступен на `http://localhost:5173`

## Как пользоваться

1.  **Выберите реакцию**: Начните с выбора реакции через список "Quick Select" или выберите атомы (например, `Na`, `Cl`, `H`, `O`) в таблице Менделеева и нажмите "Check Reaction".
2.  **Установите цель**: Выберите, что вы хотите сделать: максимизировать выход продукта или минимизировать время.
3.  **Запустите эксперименты**: Система предложит начальные условия. Нажмите "Get Predicted Conditions", затем введите ваш "фактический" результат, чтобы увидеть, как алгоритм адаптируется на следующей итерации.
4.  **Спросите ИИ**: Откройте окно чата ChemAI в любой момент во время процесса и задайте вопросы о текущем состоянии эксперимента.

## Стек технологий

*   **Frontend**: React, Vite, React Router DOM
*   **Backend**: Node.js, Express, CORS
*   **Monorepo**: npm workspaces / concurrently
