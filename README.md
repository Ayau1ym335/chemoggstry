# Chemoggstry

## Требования
- Node.js (рекомендуется v18+)

## Установка
```bash
npm install
cd backend && npm install
cd ../frontend && npm install
```

## Запуск
Для запуска одновременно Backend и Frontend (используя concurrently):
```bash
npm run dev
```

- Backend порт: 4000
- Frontend порт: 5173
