# Demo Paths — Эталонный файл для TASK 33 (тюнинг алгоритма)

> Этот файл фиксирует ожидаемую последовательность шагов алгоритма оптимизации
> (жадный nearest-match) для каждой из 5 реакций на основе `experiments_dataset.json`.
> Используется в TASK 33 как эталон: реальный алгоритм должен давать схожие или лучшие пути.

---

## Модель yield (общая формула)

```
yield = base + peak × gaussian(T, C, t; optimum, sigma) + catalystBonus + noise
```

- **gaussian** — многомерное гауссово ядро: unimodal, пик = 1.0 в точке оптимума
- **noise** — детерминированный псевдошум ±1 пп (воспроизводимый)
- **catalystBonus** — аддитивная константа при наличии катализатора

## R1 — Нейтрализация: HCl + NaOH

**Оптимум:** T=50°C, C=0.6 M, t=20 min, cat=None
**Диапазон yield в датасете:** 47.4 – 88.6%

| Шаг | T (°C) | C (M) | cat  | t (min) | yield |
|-----|--------|-------|------|---------|-------|
| **Start** | 20 | 0.1 | None | 5 | **47.6%** |
| Iter 1 | 30 | 0.1 | None | 5 | 52.4% |
| Iter 2 | 50 | 0.3 | None | 10 | 73.1% |
| Iter 3 | 50 | 0.5 | None | 20 | 86.6% |
| **Iter 4** | **50** | **0.6** | **None** | **20** | **88.6%** |

**Итоговый прирост: +41.0 пп** (>15 пп минимум)

Ключевые наблюдения:
- T=50°C — чёткий пик; при 40 и 60°C yield значительно ниже
- C=0.6M — оптимум; ниже 0.3M и выше 0.8M уже заметный спад
- t>20 мин не даёт прироста (нейтрализация — быстрая реакция)

## R3 — Разложение перекиси водорода: 2H2O2 → 2H2O + O2

**Оптимум:** T=45°C, C=18%, t=35 min (t=20 min с катализатором)
**CatalystBonus:** MnO2=+15 пп, KI=+9 пп
**Диапазон yield в датасете:** 34.6 – 87.1%

| Шаг | T (°C) | C (%) | cat   | t (min) | yield |
|-----|--------|-------|-------|---------|-------|
| **Start** | 20 | 3 | None | 5 | **34.6%** |
| Iter 1 | 40 | 9 | None | 20 | 59.4% |
| Iter 2 | 45 | 18 | None | 35 | 72.1% |
| Iter 3 | 45 | 18 | MnO2 | 35 | 87.1% |
| **Iter 4** | **45** | **18** | **MnO2** | **20** | **86.3%** |

**Итоговый прирост: +52.5 пп** (>15 пп минимум)

Ключевые наблюдения:
- Переключение None → MnO2 — самый большой единичный скачок (+15 пп)
- Алгоритм должен исследовать катализаторы после нахождения T,C-оптимума
- С MnO2 реакция завершается быстрее (t=20 мин достаточно)

## R4 — Синтез этилацетата: CH3COOH + C2H5OH → CH3COOC2H5 + H2O

**Оптимум:** T=80°C, C=3 M, t=90 min, cat=H2SO4
**CatalystBonus:** H2SO4=+22 пп
**Диапазон yield в датасете:** 26.0 – 87.8%

| Шаг | T (°C) | C (M) | cat    | t (min) | yield |
|-----|--------|-------|--------|---------|-------|
| **Start** | 50 | 1 | None | 30 | **26.0%** |
| Iter 1 | 70 | 2 | None | 60 | 51.9% |
| Iter 2 | 80 | 3 | None | 90 | 65.8% |
| Iter 3 | 80 | 3 | H2SO4 | 90 | 87.8% |
| **Iter 4** | **80** | **3** | **H2SO4** | **90** | **87.8%** |

**Итоговый прирост: +61.8 пп** (>15 пп минимум)

Ключевые наблюдения:
- Самый большой общий прирост среди всех реакций
- H2SO4 даёт +22 пп — катализатор критичен для этерификации
- T=80°C оптимальна (90°C уже хуже — начинается разложение)
- Iter 4 = Iter 3 — алгоритм уже в оптимуме (конвергировал за 3 шага)

- t=6s достаточно; Iter 4 = Iter 3 (конвергировал за 3 шага)
