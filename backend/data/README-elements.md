# Elements Data (MVP Subset)

NOTE: The data in `elements.json` is a deliberate subset of the Periodic Table (21 elements) for the MVP. 
It covers ONLY the elements needed for the 5 preset reactions (from TASK 6) plus a few of their immediate neighbors to make the UI look cohesive.
It is NOT the full 118 elements. This is an intentional simplification to keep the MVP scope manageable. It can be expanded post-MVP.
